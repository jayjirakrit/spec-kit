## Verifiable tasks (added by the `serichai` preset)

Every task MUST end with a short `Verify:` note naming how it is checked (a command,
test, or observable behavior). Keep tasks minimal; do not split write-test / write-code /
refactor into separate tasks unless parallelization or review requires it.

If `design.md` exists, load it with the other design artifacts and align task file paths
with it.
